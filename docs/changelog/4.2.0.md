### 4.2.0

_Not Released Yet_

#### Fixes

- Fixed environment variables whose value contains `=` being exported truncated.
- Fixed `vswhere` output with multiple installations being used as a single,
  corrupted path. The first reported installation is used now.
- Fixed `INCLUDE` not being de-duplicated while all variables except `PATH`,
  `INCLUDE`, `LIB` and `LIBPATH` were. Only those four are de-duplicated now.
